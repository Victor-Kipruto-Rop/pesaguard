
# PesaGuard Documentation

This directory is organized by system concern:

- `architecture/` - system and service design
- `api/` - public API contracts
- `integrations/` - payment and communications providers
- `domains/` - transaction, reconciliation, fraud, identity, reporting, and audit behavior
- `database/` - schema, migrations, retention, backups, and restore procedures
- `security/` - security controls and threat management
- `infrastructure/` - local and hosted platform setup
- `operations/` - deployment and operational procedures
- `runbooks/` - incident-specific response guides
- `development/` - contribution and engineering workflow
- `testing/` - test strategy and test data
- `observability/` - logs, metrics, traces, health checks, and SLOs
- `compliance/` - governance and residency requirements
- `product/` - product scope and workflows
- `decisions/` - architecture decision records
